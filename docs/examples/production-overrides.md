# Production Override Patterns

`vibewarden.production.yaml` is **deep-merged on top of `vibewarden.yaml`** at bundle time
(`vibew bundle`) and at runtime when `VIBEWARDEN_ENV=production`. Only keys you set here
override their dev counterparts; everything else stays as declared in `vibewarden.yaml`.

Start from the minimal file generated by `vibew init` and add only the stanzas you need.

---

## upstream

Override the upstream host and port when the production service name or port differs from dev.

```yaml
upstream:
  host: "app"
  port: 3000
```

---

## app

Pin the Docker image tag used in production. Replace `myapp` with your project name.

```yaml
app:
  image: "myapp:latest"
```

---

## log

Set structured JSON logging and verbosity for production.

```yaml
log:
  level: "info"
  format: "json"
```

---

## security_headers

Enable HTTP security headers. All options below reflect production-hardened defaults.

```yaml
security_headers:
  enabled: true
  hsts_max_age: 31536000
  hsts_include_subdomains: true
  hsts_preload: true
  content_type_nosniff: true
  frame_option: "DENY"
  content_security_policy: "default-src 'self'; style-src 'self' 'unsafe-inline'"
  referrer_policy: "strict-origin-when-cross-origin"
  permissions_policy: "geolocation=(), microphone=(), camera=()"
```

---

## rate_limit

Throttle requests per source IP. Adjust `requests_per_second` and `burst` to match your
traffic profile. Add paths to `exempt_paths` that must never be rate-limited (e.g. health
endpoints polled by load balancers).

```yaml
rate_limit:
  enabled: true
  trust_proxy_headers: false
  per_ip:
    requests_per_second: 20
    burst: 40
  exempt_paths:
    - "/health"
```

---

## waf

Enable the Web Application Firewall. Use `mode: block` in production to actively reject
malicious requests. Use `mode: detect` during initial rollout to observe without blocking.

```yaml
waf:
  enabled: true
  mode: block
```

---

## auth

Enable JWT authentication. Set `jwks_url` to your identity provider's JWKS endpoint.
`public_paths` lists paths that bypass authentication entirely (e.g. health probes).

```yaml
auth:
  mode: jwt
  jwt:
    jwks_url: "https://your-idp/.well-known/jwks.json"
    issuer: "https://your-idp/"
    audience: "https://api.example.com"
  public_paths:
    - /health
```

---

## admin

Enable the VibeWarden admin API. The token is read from the environment variable at runtime —
never hard-code a secret in the config file.

```yaml
admin:
  enabled: true
  token: "${VIBEWARDEN_ADMIN_TOKEN}"
```

---

## kratos

Override the Ory Kratos public URL when Kratos runs on a different host or port in production.

```yaml
kratos:
  public_url: "http://kratos:4433"
```
